转换说明

  • API 搜索 + API 选集：自动转换 searchApiConfig / chapterApiConfig。
  • API 搜索 + XPath 选集：自动使用 sourceTemplate + chapterRoads/chapterResult。
  • XPath 搜索 + XPath 选集：自动转换 searchURL/searchList/chapterRoads。
  • episodePage、variables、antiCrawlerConfig 不会自动转换，会写进规则的 _warnings。
  • API 规则不会自动映射 vod_pic/vod_content 等字段，导入后可在 fields 里补。
